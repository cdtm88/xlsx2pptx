Saving & data Autosaves to this browser as you type
With a project file every change is written straight into it, so the file on disk is always current and you can keep it beside the rest of the project. One file per project — open a different one to switch. Without one everything sits in this browser, which every copy of this tool shares, so only one project can live there at a time. Save JSON still downloads a standalone copy to hand to someone else or keep as a version.
